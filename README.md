# موقع نافِس

صفحات ثابتة لتطبيق **نافِس** — مسابقة الأسئلة بين الفِرَق.
تُنشر عبر GitHub Pages لتوفير الرابطين اللذين يشترطهما App Store.

| الصفحة | الملف | الغرض |
|---|---|---|
| الرئيسية | `index.html` | تعريف بالتطبيق — رابط **Marketing URL** |
| الدعم | `support.html` | أسئلة شائعة وتواصل — رابط **Support URL** (إلزامي) |
| الخصوصية | `privacy.html` | سياسة الخصوصية — رابط **Privacy Policy URL** (إلزامي) |

كل صفحة **ملفٌ واحد مكتفٍ بذاته**: الأنماط والصور مدمجة داخلها، فلا تحتاج أي ملف مرافق.
ارفع الملفات الثلاثة وحدها ويعمل الموقع. باتجاه RTL، ويعمل على الجوال والحاسوب.

## قبل النشر

- [x] بريد الدعم المعتمد: `adnalrahbi@gmail.com` في `support.html` و`privacy.html`.
- [ ] حدّث تاريخ «آخر تحديث» في `privacy.html` عند أي تعديل على السياسة.

## تفعيل GitHub Pages

Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)`.

يصير الموقع على `https://<اسم-المستخدم>.github.io/nafis-site/`.
ولربط نطاق خاص: أضف ملف `CNAME` فيه النطاق، واضبط سجلّات DNS كما تشرح صفحة Pages.

## التعديل

الملفات مصدرها مجلّد `docs/` في مستودع التطبيق، وتُنشر هنا بـ`git subtree`.
عدّل هناك ثم انشر — لا تعدّل هنا مباشرةً حتى لا تتفرّع النسختان.
